Model durumu okunuyor…

Önerilen: Qwen3-0.6B-Instruct ONNX (Apache-2.0), yaklaşık 648 MB WebGPU ağırlığı. Bu ayar sayfası sizden habersiz ağ isteği yapmaz. Model, proje klasöründe Node.js komutuyla kullanıcı onayı alınarak yüklenir. GitHub README / İşlem 004 belgesine bakın.

npm install
npm run build:runtime
npm run model:install -- --accept-license --backend=webgpu
npm run model:verify

Silmek için: npm run model:remove -- --confirm. Güncel model dosyaları kurulu değilse otomatik TextRank fallback etkindir.
