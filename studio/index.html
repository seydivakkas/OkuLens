3. Mimari ve kurulum

Bu stüdyo, yüklenen AI;DR HTML örneğinin Chrome MV3 kısıtlarına uygun olarak yeniden yazılmış, tamamı yerel JavaScript modülleri kullanan uyarlamasıdır.

Arayüz

Yüzen balon: seçim ve mikro-özet. Native Side Panel: uzun analiz. Stüdyo: bağımsız inceleme.

İşleme

Kaynak ayrıştırma → bölümlendirme → TF-IDF/TextRank → varsa yerleşik AI → görünür fallback.

Gizlilik

Uzak LLM API yok; model indirme bu sürümde yok. Örnek veri dışarı aktarılmaz.

Paketlenmemiş yükleme

Chrome: chrome://extensions · Edge: edge://extensions → Geliştirici modu → Paketlenmemiş öğe yükle → proje klasörü.
